MUHAMMAD ZAIN UL ABIDEEN — CREATIVE PORTFOLIO

Extract this ZIP first. Keep index.html, favicon.svg, vercel.json and the assets
folder at the project root, with the assets subfolders intact.

VERCEL + GITHUB
Upload the extracted files (not the ZIP) to your GitHub repository, then import
that repository into Vercel. Use Framework: Other; Build Command: empty;
Output Directory: . (one dot). The included vercel.json sets these values.

VERCEL CLI
With Node.js installed, open a terminal in the extracted directory and run:
  npx vercel --prod
Follow the account and project prompts. No website build is needed.
